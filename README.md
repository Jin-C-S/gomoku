# 五子棋（Gomoku）

基于 C/C++ 与 EasyX 图形库（Windows / MinGW GCC）实现的五子棋对弈程序。

## 功能概览
- **棋盘渲染**：9/13/15 路棋盘动态布局；经典/深色/浅色主题；棋子三材质（经典/玉石/金属，逐像素预渲染贴图）
- **对弈模式**：人人对弈 / 人机对弈 / 网络对弈（Winsock TCP）/ AI 测试（简单 AI 执黑 vs 困难 AI 执白自动对弈）
- **AI**：简单 AI（贪心启发，全盘攻防评分）；困难 AI（Negamax + Alpha-Beta 剪枝 + 迭代加深）
- **规则与对局**：禁手规则（三三/四四/长连）、落子提示、每方总时/步时、悔棋、求和
- **棋谱**：对局保存与回放（`replays/*.gmk`，文本格式）
- **音频**：MCI 播放 BGM / 落子与胜负音效，音量独立控制，零第三方依赖
- **设置**：`settings.ini` 持久化（主题、材质、音量、AI 难度等）

## 编译
用 VS Code 任务“C/C++: 编译五子棋 (g++ 全项目)”即可，等价于：

```bash
g++ -std=gnu++20 -O2 -fexec-charset=GBK gomoku.cpp ai.cpp settings.cpp audio.cpp network.cpp replay.cpp \
    -o gomoku.exe -leasyx -lgdi32 -lwinmm -lws2_32
```

> 说明：源码为 UTF-8，`-fexec-charset=GBK` 让 EasyX(ANSI) 正确显示中文。
